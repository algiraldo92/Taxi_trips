*Taxi Trips Analysis*
---
This project focuses on the analysis of taxi trip data in Chicago using Python, data analysis techniques, web scraping, and statistical hypothesis testing to uncover patterns in ride demand, destination trends, company performance, and weather-related impacts on trip duration.

*Project Overview*
---
The analysis explores taxi trip datasets from Chicago and combines multiple data sources to answer key business questions such as:

Which neighborhoods receive the highest number of taxi trips?
Which taxi companies dominate the market?
Does weather affect trip duration between downtown Chicago and O'Hare Airport?

The project includes data cleaning, exploratory data analysis (EDA), visualization, and statistical testing to generate actionable insights.

*Key Features*
---
Data Cleaning & Preprocessing
Missing values detection
Duplicate identification and removal
Data type validation
Web Scraping
Extraction of weather records using BeautifulSoup
Exploratory Data Analysis (EDA)
Analysis of taxi companies by number of trips
Neighborhood destination trends
Visualization of top-performing taxi companies and popular drop-off locations
Statistical Analysis
Levene Test to evaluate variance equality
Independent T-Test to test whether weather conditions significantly impact trip duration

*Main Insights*
---
Certain neighborhoods (such as Loop and River North) receive the highest average number of taxi trip drop-offs.
Some taxi companies clearly dominate the market in terms of trip volume.
Statistical hypothesis testing was used to evaluate whether rainy Saturdays affect travel time between Loop and O'Hare Airport.

*Conclusions*
---
The analysis showed that weather conditions have a significant impact on taxi trip duration between downtown Chicago (Loop) and O’Hare International Airport.
Trips on rainy days tend to take longer compared to trips on days with good weather, confirming that weather is an important factor affecting urban transportation efficiency.
Through statistical hypothesis testing, it was possible to validate that this difference was not due to chance, but rather reflects a meaningful pattern in the data.
